# 💚 Finanzas Mozares

App de finanzas familiar con Firebase + Next.js

## 🚀 Features

- ✅ Presupuesto mensual
- ✅ Gestión de cuentas
- ✅ Transacciones
- ✅ Firebase Realtime Database
- ✅ Responsive (web, móvil, tablet)

## 🌐 URL Live

https://finanzas-mozares.vercel.app

## 📝 Uso

1. Elige Él 💙 o Ella 🧡
2. Usa dashboard, presupuesto, cuentas, transacciones
3. Los datos se guardan automáticamente en Firebase
